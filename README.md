## Latar Belakang Proyek
Proyek ini bertujuan untuk menganalisis *Bike Sharing Dataset* guna memahami pola dan tren penyewaan sepeda harian maupun per jam. Analisis ini mengeksplorasi pengaruh faktor musim, kondisi cuaca, hari kerja, serta waktu terhadap tingkat penggunaan layanan sepeda. Selain itu, proyek ini juga menyediakan dashboard interaktif berbasis *Streamlit* untuk menyajikan visualisasi data secara dinamis.
